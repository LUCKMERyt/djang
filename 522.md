# Cloudflare error 522 — connection timed out

Cloudflare could not connect to the origin in time, or the origin stopped
responding during connection setup.

## What to check

1. Verify the origin is online and its public IP in Cloudflare DNS is current.
2. Check whether the origin is overloaded or dropping connections.
3. Review firewall, rate-limit, and network-device logs; make sure Cloudflare's
   published IP ranges are not blocked or rate-limited.
4. Check origin network routing and keep-alive settings with the hosting
   provider.

Compare the error timestamp and Ray ID with origin and network logs. A request
that never reached Django must be diagnosed at the origin/network layer.

Reference: [Cloudflare error 522](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-522/)
