# Cloudflare error 520 — unknown origin response

Cloudflare received an empty, malformed, or unexpected response from the origin.
The request may have reached the origin, but Django may not have generated the
response correctly.

## What to check

1. Match the timestamp and Ray ID with Django, web-server, proxy, and firewall
   logs.
2. Check for origin restarts, crashes, malformed HTTP responses, or oversized
   request/response headers (for example, excessive cookies).
3. Verify that the origin's HTTP/2 and TLS settings match what the server
   actually supports.
4. Confirm that security software is not blocking Cloudflare's published IP
   ranges.

Collect the full error page, URL, timestamp, Ray ID, and matching origin logs.
This is an origin/proxy response issue, not something a Django error template
can repair.

Reference: [Cloudflare error 520](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-520/)
