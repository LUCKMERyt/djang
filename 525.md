# Cloudflare error 525 — SSL handshake failed

Cloudflare could not complete the TLS handshake with the origin. This usually
occurs when the zone uses **Full** or **Full (strict)** SSL/TLS mode and the
origin's HTTPS endpoint is unavailable or incompatible.

## What to check

1. Confirm the origin is listening on HTTPS on the configured port (usually
   `443`).
2. Check the origin TLS certificate, SNI configuration, supported protocol
   versions, and cipher compatibility.
3. Review web-server TLS error logs at the time of the failure.
4. Verify the Cloudflare SSL/TLS mode matches the origin configuration.

Do not send private keys or certificate private material when sharing logs.
Use a valid origin certificate and keep end-to-end TLS enabled.

Reference: [Cloudflare error 525](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-525/)
