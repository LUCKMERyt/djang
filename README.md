# SOPHISTICATED

**SOPHISTICATED — кураторская витрина вещей для осознанного повседневного выбора.**

Это русскоязычный Django-сайт не про бесконечный каталог, а про внимательное
отношение к вещам. Пользователь может изучить материалы, назначение и наличие
товара, познакомиться с командой, прочитать журнал и оставить отзыв. Главная
идея проекта — помочь выбрать не случайную покупку, а вещь, которая естественно
останется частью жизни.

## Что есть на сайте

- **Главная** — манифест проекта, направления каталога, принципы отбора и отзывы.
- **Кураторская витрина** — товары с поиском, фильтрами по категории и материалу,
  сортировкой, фильтром наличия и подробным модальным окном.
- **Люди за выбором** — команда проекта с описаниями и контактами.
- **Журнал выбора** — статьи о материалах, происхождении вещей и осознанном выборе.
- **Философия** — объяснение идеи SOPHISTICATED и критериев отбора.
- **Отзывы** — публикация оценок и отзывов посетителей.
- **Аккаунт** — регистрация, вход по email и личный кабинет.

## Локальный запуск

Команды выполняются из каталога `Al_Ven`.

Для локальной работы на SQLite:

```powershell
$env:DB_ENGINE = "sqlite"
..\.venv\Scripts\python.exe manage.py migrate
..\.venv\Scripts\python.exe manage.py runserver
```

По умолчанию проект настроен на MySQL. Для него задайте параметры окружения:

```powershell
$env:DB_ENGINE = "mysql"
$env:DB_NAME = "djangoo"
$env:DB_USER = "root"
$env:DB_PASSWORD = Read-Host "Пароль MySQL"
$env:DB_HOST = "127.0.0.1"
$env:DB_PORT = "3306"
..\.venv\Scripts\python.exe manage.py migrate
..\.venv\Scripts\python.exe manage.py runserver
```

База `djangoo` должна быть создана заранее. Для production необходимо задать
собственный `DJANGO_SECRET_KEY`, список `DJANGO_ALLOWED_HOSTS`,
`DJANGO_DEBUG=False` и настроить HTTPS. Секреты не должны попадать в Git.

## Проверки

```powershell
$env:DB_ENGINE = "sqlite"
..\.venv\Scripts\python.exe manage.py check
..\.venv\Scripts\python.exe manage.py test hello.tests
..\.venv\Scripts\python.exe manage.py makemigrations --check --dry-run
```

## Технологии

- Python и Django;
- SQLite для локальной разработки или MySQL для рабочего окружения;
- Django ORM и стандартная система пользователей;
- HTML-шаблоны Django, CSS и небольшой JavaScript без отдельного frontend-фреймворка;
- изображения товаров и сотрудников в `Al_Ven/media/`.

## Важные каталоги

```text
Al_Ven/
├── manage.py
├── Al_Ven/                  # настройки и маршруты проекта
├── hello/                   # основное приложение
│   ├── models.py            # товары, категории, команда, отзывы
│   ├── views.py             # страницы и обработчики
│   ├── forms.py             # формы регистрации и отзывов
│   ├── templates/           # страницы сайта
│   └── static/css/          # стили сайта и админки
├── media/                   # изображения товаров и сотрудников
└── db.sqlite3               # локальная база SQLite
```
