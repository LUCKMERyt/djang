# Cloudflare error 526 — invalid origin SSL certificate

Cloudflare could not validate the origin certificate while **Full (strict)**
SSL/TLS mode is enabled.

## What to check

1. Verify the certificate is current, trusted (or configured in an applicable
   origin trust store), and issued for the requested hostname.
2. Ensure the origin sends the complete certificate chain, including required
   intermediate certificates.
3. Confirm the origin serves the intended certificate on the configured HTTPS
   port.
4. Check the certificate and web-server logs around the error timestamp.

Use a valid certificate for the origin. Switching away from **Full (strict)**
may help isolate the cause, but should not be treated as a permanent fix that
weakens origin verification.

Reference: [Cloudflare error 526](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-526/)
