# Карта файлов проекта SOPHISTICATED

Этот документ объясняет, **какой файл за что отвечает**. Пути указаны относительно
корня репозитория `D:\djang`.

Для запуска смотрите [`README_QUICKSTART.md`](README_QUICKSTART.md), для логики —
[`README_ARCHITECTURE.md`](README_ARCHITECTURE.md), для анимаций —
[`README_ANIMATIONS.md`](README_ANIMATIONS.md), для контекста ассистента —
[`AI_CONTEXT.md`](AI_CONTEXT.md).

Обозначения:

- **Приложение** — файл влияет на работу сайта;
- **Данные** — база, дампы, фотографии;
- **Проверки** — диагностика и отчёты;
- **Архив / служебное** — старые скрипты, заметки, логи; удалять или переиспользовать только осознанно.

## 2. `Al_Ven/` — Django-проект

### 2.1. Точки входа и локальная база

| Файл | Тип | Зачем нужен |
| --- | --- | --- |
| `Al_Ven/__init__.py` | Приложение | Метка пакета Python для каталога `Al_Ven`. |

### 2.2. Пакет настроек `Al_Ven/Al_Ven/`

| Файл | Тип | Зачем нужен |
| --- | --- | --- |
| `__init__.py` | Приложение | Метка пакета Python. |
| `settings.py` | Приложение | Все настройки проекта: `DEBUG`, `SECRET_KEY`, `ALLOWED_HOSTS`, выбор БД (`DB_ENGINE=mysql|sqlite`), `INSTALLED_APPS`, middleware, шаблоны, `STATIC_*`/`MEDIA_*`, email, `ADMINS`, контакты `SITE_*`, ID аналитики `YMETRICA_ID`/`GA_MEASUREMENT_ID`, флаги безопасности и оформление Jazzmin. |
| `urls.py` | Приложение | Карта URL сайта. Важно: для товаров используются `<str:slug>`, потому что встроенный `slug`-конвертер Django принимает только ASCII и не понимает кириллицу. Есть дубль маршрута `name='index'` для `''` и `'index/'` — историческая странность, `reverse('index')` даёт `/index/`. В `DEBUG` здесь же подключается раздача `/media/`. |
| `wsgi.py` | Приложение | Точка входа WSGI для production-серверов (Gunicorn/uWSGI и т. п.). |
| `asgi.py` | Приложение | Точка входа ASGI для асинхронных серверов. |
| `templates/admin/index.html` | Приложение | Переопределяет главную страницу Django Admin: дашборд в стиле «накладной» с быстрыми действиями (добавить товар/категорию/сотрудника, перейти к отзывам). Подключается через `TEMPLATES['DIRS']`. |

## Важные замечания

1. **Старые credential-bearing `dsdsd.txt` удалены из рабочего дерева и собранной статики.** Если их содержимое попадало в Git или публиковалось, ранее сохранённые пароли нужно сменить: удаление текущих файлов не очищает историю.
2. **Скрипты `fill_product_slugs.py`, `verify_slugs.py`** используют переменные среды для доступа к MySQL; секретов в них нет.
3. **Текущая проверенная конфигурация:** 28 тестов, миграции 0001–0013.
4. **`reverse('index')` возвращает `/index/`** из-за двух маршрутов с именем `index`. Это известная странность, её не меняют без отдельного запроса.
5. **Удалять файлы из корня не следует без уточнения**: логи, дампы и скрипты могли быть созданы вручную и не являться частью приложения, но быть кому-то нужны.
