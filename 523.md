# Cloudflare error 523 — origin is unreachable

Cloudflare cannot route to the origin web server. This commonly points to an
incorrect origin IP or a routing problem between Cloudflare and the host.

## What to check

1. Verify the A/AAAA records in Cloudflare DNS point to the current origin IP.
2. Ask the hosting provider to check routing, gateway, and network outages.
3. Check origin and network-device logs around the error time.
4. If the origin is behind a tunnel or private network, verify that the
   connector and route to the origin are healthy.

Collect the full error page, URL, time, Ray ID, and the expected origin address.
Do not expose private IPs or network diagrams publicly.

Reference: [Cloudflare error 523](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-523/)
