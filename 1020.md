# Cloudflare error 1020 — access denied

Cloudflare blocked the request because a security feature or rule matched it.
This is an edge security decision, not a Django authorization response.

## If you are a visitor

Send the site owner a screenshot of the error, the requested URL, the time and
timezone, and the Cloudflare Ray ID. Do not repeatedly retry or try to bypass
the site's security rules.

## If you manage the site

1. Find the matching request in Cloudflare **Security Events** using its Ray ID
   or client IP and timestamp.
2. Identify the exact rule or security feature that blocked it.
3. Adjust only the rule that caused the false positive, then retest the
   intended request.

Do not broadly disable WAF/security rules to resolve one blocked request.

Reference: [Cloudflare error 1020](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1020/)
