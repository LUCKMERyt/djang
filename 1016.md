# Cloudflare error 1016 — origin DNS error

Cloudflare could not resolve the origin hostname to an IP address.

## What to check

1. Check the origin's A/AAAA record or, if using a CNAME, confirm its target
   exists and resolves publicly.
2. Confirm the DNS record belongs to the correct Cloudflare zone and that the
   origin hostname is spelled correctly.
3. If using a load balancer or custom hostname, verify its origin/pool and
   fallback configuration.
4. Allow time for DNS changes to propagate, then test resolution again.

The DNS record must point to the production origin; `127.0.0.1` and
`runserver` are only for local development.

Reference: [Cloudflare error 1016](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1016/)
