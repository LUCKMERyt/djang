# Cloudflare error 524 — origin response timed out

Cloudflare connected to the origin, but the origin did not return an HTTP
response before the applicable proxy read timeout.

## What to check

1. Find the slow request in application, database, and web-server logs using
   its timestamp and Ray ID.
2. Check for slow database queries, external service calls, overloaded workers,
   or long synchronous jobs.
3. Optimize or move long-running work to a background job with a status/polling
   endpoint instead of keeping one HTTP request open.
4. If the timeout affects only large uploads, check the relevant proxy write
   timeout and upload limits.

Raising a timeout is not always available or appropriate; first identify why
the request is slow. A Django template cannot fix an upstream timeout.

Reference: [Cloudflare error 524](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-524/)
