# Ошибка 1033 — Cloudflare Tunnel

Cloudflare error `1033` means Cloudflare cannot find a healthy `cloudflared`
connector for the requested Tunnel hostname. The request has not reached this
Django application; a Django template or URL change cannot repair the Tunnel.

## Проверки

1. In Cloudflare Zero Trust, open **Networks → Tunnels** and check that the
   expected Tunnel is **Active**.
2. On the origin host, run `cloudflared tunnel list` and verify the connector
   process/service is running. Review its logs for connection or authentication
   failures.
3. Check that the public hostname is routed to the intended Tunnel and that its
   DNS record points to that Tunnel.
4. Verify the Tunnel's origin service URL and port. The origin must be reachable
   from the machine running `cloudflared`; Django's development server is not a
   production server.
5. If the Tunnel is active but 1033 continues, compare the hostname and DNS
   target in the Cloudflare dashboard and review the Cloudflare Ray ID and
   timestamp.

Never commit or share Tunnel tokens, credential JSON files, private keys or
other authentication material.

Reference: [Cloudflare Tunnel common errors](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/troubleshoot-tunnels/common-errors/)
