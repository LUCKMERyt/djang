# Cloudflare error 521 — web server is down

Cloudflare could not establish a connection because the origin server refused
it. The origin may be offline, or a firewall/security service may be rejecting
Cloudflare's connections.

## What to check

1. Confirm the production web server is running and listening on the configured
   origin port. Django's `runserver` is for local development, not production.
2. Review origin and firewall logs for refused or blocked connections.
3. Allow Cloudflare's current published IP ranges in the origin firewall; do
   not disable the firewall wholesale.
4. Confirm the origin port and Cloudflare SSL/TLS mode agree (HTTP or HTTPS).

Collect the URL, time, Ray ID, and origin/firewall logs for the same request.

Reference: [Cloudflare error 521](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-521/)
